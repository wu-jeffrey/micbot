# MICBot MVP Plan

## Chunk 1A

Build the raw ledger and wiki projection:

- Capture raw messages/events into SQLite.
- Add distilled memory entries manually through the CLI.
- Regenerate Markdown wiki files from SQLite.
- Verify the chain with tests.

## Later Chunks

Future chunks may add OpenClaw capture conventions, intake workflows, quoting support, job tracking, printer selection, and controlled automation. Do not start those until Chunk 1A is stable.
